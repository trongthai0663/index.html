5. Vị trí dấu đánh dấu (Outside vs Inside)

Outside (Mặc định - Dấu đánh dấu nằm ngoài khối nội dung):

  • HTML - Ngôn ngữ đánh dấu siêu văn bản dùng để dựng cấu trúc trang.
  • CSS - Ngôn ngữ định kiểu cho trang web đẹp hơn.

Inside (Dấu đánh dấu nằm trong khối nội dung):

  • HTML - Ngôn ngữ đánh dấu siêu văn bản dùng để dựng cấu trúc trang.
  • CSS - Ngôn ngữ định kiểu cho trang web đẹp hơn.
